# Minigame 1

## Devlog

Ash Nguyen, he/him





The relationship between Components, GameObjects, and Scenes can be described as assembling pieces of a puzzle in a frame. In a 3D environment, this metaphor can be described more loosely when imagining the scene as the "frame", GameObjects as the "puzzle pieces", and the art on the "puzzle pieces" being the components that make up a GameObject. This can be related to a technique people use when putting together puzzles where they put the pieces together inside of a picture frame so that they can preserve the puzzle as a piece of art within their own home. This is like how components of GameObjects within a scene can make up a game composed of the scene containing the GameObjects and components.
